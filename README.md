# React-Ionic-App
An Ionic project built with **React** and **TypeScript**. It uses Ionic UI components with React Router for navigation.

## Features
- Ionic 4 UI components with React
- Routing via `react-router` and `react-router-dom`
- TypeScript support
- Responsive mobile-first UI
- Example `Home` page with links to Ionic documentation and author’s GitHub

## Prerequisites
- **Node.js:** >= 8.9.4
- **npm:** >= 5.6.0

## Installation
```
git clone https://github.com/amitesh786/ionic-react-app
cd React-Ionic-App
npm install
```

## Running the App
- `npm start`: visit http://localhost:3000 in your browser.

## Building for PROD
- `npm run build`: this generates an optimized build in the `build/` folder.

## Testing
- `npm test`
